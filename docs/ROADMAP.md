# Research Roadmap

## Status vocabulary

- **Complete:** implemented and proportionally checked.
- **In progress:** useful work exists; material work remains.
- **Planned:** defined but not started.
- **Blocked:** a named dependency prevents valid progress.
- **Deferred:** intentionally later.
